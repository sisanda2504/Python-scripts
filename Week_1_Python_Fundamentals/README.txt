PYTHON UTILITIES PACK
=====================

This pack contains five Python scripts created for Week 1: Python Fundamentals.

1. system_info.py
   Concepts: variables, data types, modules
   Purpose: Displays basic computer and Python information.

2. password_checker.py
   Concepts: operators, conditions, logical expressions, strings
   Purpose: Checks password strength using basic password rules.

3. user_account_validator.py
   Concepts: loops, strings, lists, tuples
   Purpose: Processes and validates a list of user accounts.

4. device_record_manager.py
   Concepts: dictionaries, functions, reusable code
   Purpose: Stores, displays and adds IT device records.

5. file_checker.py
   Concepts: exceptions, modules, basic testing
   Purpose: Checks file information and handles common errors.

HOW TO RUN
==========
Open a terminal in this folder and run:

python system_info.py
python password_checker.py
python user_account_validator.py
python device_record_manager.py
python file_checker.py

If "python" does not work on Windows, try:
py filename.py

SCRUM NOTES
===========
What has been completed?
- Five working Python utilities covering the main Week 1 Python concepts.
- Used variables, conditions, loops, collections, functions, modules and error handling.

What Python concepts remain unclear?
- Possible areas to continue practising are exception handling, writing reusable functions,
  and understanding when to use lists, tuples and dictionaries.

What technical blockers were experienced?
- Python installation/path configuration can prevent the python command from running.
- User input can cause errors if it is not validated.
- File paths can be incorrect or inaccessible.

How could the scripts support an IT department?
- System Information Utility can help collect device information during troubleshooting.
- Password Checker can encourage users to create stronger passwords.
- User Account Validator can help identify incorrect or inactive account records.
- Device Record Manager can keep simple records of company devices.
- File Checker can confirm files exist and help diagnose file-access problems.
