# Python Automation Utilities

A collection of Python scripts developed during my practical training in Python programming, operating-system automation, troubleshooting, and version control.

## Project Overview

This repository demonstrates the use of Python to automate common IT and operating-system tasks. The project covers Python fundamentals, file management, regular expressions, system monitoring, and Git version control.

## Week 1: Python Fundamentals

### System Information
`system_info.py`

Displays basic information about the computer system.

### Password Checker
`password_checker.py`

Checks a password against defined password-strength requirements.

### User Account Validator
`user_account_validator.py`

Processes and validates user account information.

### Device Record Manager
`device_record_manager.py`

Uses dictionaries and functions to manage device information.

### File Checker
`file_checker.py`

Demonstrates file handling and exception handling in Python.

## Week 2: Operating-System Automation

### File Organizer
`file_organizer.py`

Automatically organizes files into folders according to their file extensions.

Examples include:

- Images
- Documents
- Spreadsheets
- Python files
- Archives

### Log Analyzer
`log_analyzer.py`

Reads a log file and uses regular expressions to identify:

- Error messages
- Dates
- IP addresses

### System Health Checker
`system_health_checker.py`

Displays system information and checks system resources such as:

- Operating system
- Processor
- CPU count
- Total disk space
- Used disk space
- Available disk space
